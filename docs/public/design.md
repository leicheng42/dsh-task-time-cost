# 设计重做：把“预估”从数字改成可信的判断

> 面向长任务的设计说明。0.4.0 是这份设计的第一刀（P0），后续按 §9 迭代。

## 1. 用户到底在问什么

| 场景 | 用户真实问题 | 现状错在哪 |
|---|---|---|
| 长任务（审计、迁移、发布） | 这活儿还要多久？今晚能不能完？ | 面板在跑到 8 分钟时仍写“约 1m 还需”，完成时刻指向已经过去的 12:58 |
| 刚开工 | 现在值不值得等？ | 一上来就给“约 2m”，把长任务说成短任务 |
| 短任务 | 别打扰我 | 反而得点开面板才看到已经被误导 |

**根因不是数字算得不准，而是产品把“假设”当成了“结论”**：模板先验和模型自述的计划都被直接印成完成时刻，没有任何机制在事实与之冲突时推翻它。

## 2. 三个必须写进产品的原则

1. **预估是可被推翻的假设，不是承诺。** 一旦事实与它矛盾，产品要主动说“我错了，正在重估”，而不是继续显示旧数字。
2. **证据分档，低档不能覆盖高档。** 计划（模型自述）< 本地实测（本会话/本路由观测）< 完成事实。计划只在没有实测时用来“放量级”，不能压过已发生的工作量。
3. **任何显示都不得与已流逝的时间矛盾。** 完成时刻不能在过去；总耗时不能小于已用；剩余不能小到与已观察到的投入明显冲突。

## 3. 状态机（这次重做的核心）

| 状态 | 进入条件 | 显示 |
|---|---|---|
| 评估中 | 无计划、无本地样本 | 只给“已用”事实 + “正在评估任务”，**不给 ETA** |
| 初步 | 有计划或模板先验 | **区间** + 完成时刻区间 + 来源标签（AI 计划 / 估时模型 / 参考先验） |
| 校正 | 已用 > 初估上限，或计划剩余 < 已用/6 且已用 > 2 分钟 | 标签“已校正”；**隐藏完成时刻**；剩余按实际投入重估 |
| 稳定 | 本地样本 ≥ 5 且区间比 ≤ 2 | 才允许出现单点“约 Xm” |
| 完成 | turn 结束 | 只给事实：用时、Token、费用，不再预测 |

0.4.0 已实现：**校正态**（含标签与隐藏过去时刻）、单点被限制在稳定态之外的降级、规模驱动的模型预估。

## 4. 数字呈现规则

- **区间优先，单点靠后**：宽度就是不确定度，先让人看到“1h–6h”，再谈“约 3h”。
- **下限贴地**：`还剩` 的下界不得低于 60 秒（运行中）；`完成时刻` 不得早于现在。
- **计划是输入不是事实**：自述“还剩 1 轮”而实际已跑 500+ 步时，按步速重估，并标注“已校正”。
- **未知写 —，部分写“部分”**：不把 0 当未知，不把已知子集当总额。
- **账本精确、摘要取整**：金额在明细里保留全部小数，摘要按可读位数。

## 5. 信息层级（面板从上到下）

1. 大号 **还剩**（区间）+ 证据标签；下方一行完成时刻区间或“已超出初估”。
2. **时间轴**：开始 → 现在（实心）→ 预计完成（浅色不确定带）。
3. **三维进度**：时间 / Token / 费用，各“已用（事实）/ 还剩（预估）/ 预计总计（预估）+ 进度条”，未知用虚线。
4. **模型预估开关**：只对大任务生效，一键开关。
5. 一行脚注：价格口径、部分覆盖或校正说明。

## 6. 模型预估的产品定位

- **触发看“看起来多大”**，不是看“当前算出来多小”：长提示词（≥1200 字）、goal/program 规模，都会触发，即使模板说只要几分钟。
- **目的不是更准的秒数，而是尽早把量级放对**：把“长任务 2 分钟”纠正成“数小时”。
- **一次有界调用**、默认跟随会话路由、默认开启、失败/超时/格式错都退回模板。
- 与执行模型自己的 `task_estimate_plan` 并存：计划优先，但同样受 §3 的校正规则约束。

## 7. 明确不做

- 不承诺准确率，不给“±X%”这种伪精确。
- 不在短任务上做额外调用。
- 不保存提示词/正文；估时请求只带任务文本、只回数字。

## 8. 验收标准（这条设计算不算成立）

1. 长任务在第 1 分钟内不再出现“约 2m”这类断言，而是区间或“评估中”。
2. 任何时刻，完成时刻都不会早于当前时间；已被超过时显示校正态。
3. 短任务（预计 < 5 分钟）不触发模型调用。
4. 未知、部分、校正三种情况在界面上可区分，不靠读脚注猜。

## 9. 后续（P1/P2）

- P1：稳定态的判定阈值开放成配置；区间收窄过程可视化（历史预估轨迹）。
- P1：把“已校正”与完成后的实际误差一起记录，形成公开的校准记录（不承诺准确率，但给出实测分布）。
- P2：多任务并行时的资源排队对 ETA 的影响。
