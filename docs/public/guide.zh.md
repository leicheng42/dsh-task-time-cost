# 使用指南

[返回介绍](../../README.md) · [English](guide.en.md)

## 入口与详情

点击 Token 统计旁的时钟/预估打开浮窗。预估详情按需展开；已结束回合的操作行显示「用时」，不重复 Token。工作时间、等待用户、剩余参考和预计总时间分别理解。历史保留参考附带更新时间。

## 首次校准

先正常完成若干回合。设置中的路由画像按最近真实观测排序，显示来源、日期、样本数和可测指标。默认首正文10秒、可见正文50 tok/s、总调用30秒及0.5/2.5参考倍率均为工程起点；无合格样本时仍属参考，不代表供应商实测。

同名模型在不同 provider、端点、模式、推理设置和服务档位下不视为同一路由。SDK不能统一提供的端点身份保持 unknown；需要覆盖时只填不含秘密的稳定身份，不填 API Key 或带凭证的 URL。

## 费用和 Token

自定义费率优先，随包 models.dev 公共目录作为参考来源。参考价保留来源和版本，不代表渠道账单。complete表示当前用量/价格语义下完整估价；partial是已知子集；unpriced表示证据不足；free需要明确零价。不同币种分别展示。

输入、缓存读取、缓存写入、输出与推理按可确认的合同计量，避免重复相加。已报告 Token 小计不代表完整总量；未来工作没有完整预算时总预测保持未知。

## 管理操作

读取配置后再编辑。保存写完整配置，不能把片段当全量覆盖；高级 JSON 可包含自定义费率、路由语义和工作量模板。刷新默认5000ms，本地显示时钟1000ms；显示时钟不发 RPC。

JSON/CSV 基线包含 seedId、数据版本、任务/路由范围、来源、日期、统计口径、样本数和范围。导入按身份合并；非法批次整体拒绝。不要把均值伪装成分位数，也不要把不完整统计导出整体作为基线导入。

导出准备完成不保证用户已在系统保存对话框落盘；取消保存仍需要与成功保存区分。导出数据并非匿名，分享前按[隐私说明](privacy.md)检查。

重置校准需要确认，仅重置学习并推进 cutoff；历史用量、原始价格、配置、导入基线和 DSH 会话保留。卸载后的数据保留以当前实际验收和宿主操作选项为准，不替代备份。

## 异常与更新

空值或部分覆盖不应被理解为免费或已完成。预估不替你停止任务、切换模型或判断回合结束。存储故障会显示诊断，主任务仍由宿主执行。

更新包后按宿主要求重启。若遇到加载失败，保存当前 Console/版本/操作顺序；不用真实业务数据试清空操作，也不反复刷新或修改其他插件。报告问题时移除会话身份、端点秘密及正文。
